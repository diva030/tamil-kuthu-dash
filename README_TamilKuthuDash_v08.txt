TAMIL KUTHU DASH v0.8 — ONLINE LEADERBOARD

This is a browser game with an optional Supabase-backed online leaderboard. The leaderboard will not connect until you configure your own Supabase project.

SETUP
1. Create a project at https://supabase.com/ and open Project Settings / API (or API Keys).
2. Open the downloaded HTML file in a code editor. Find these lines near the top of the JavaScript:
   const SUPABASE_URL='YOUR_SUPABASE_PROJECT_URL';
   const SUPABASE_ANON_KEY='YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY';
   Replace them with your Project URL and publishable/anon key. Do not put a service_role/secret key in this file.
3. In Supabase, open SQL Editor and run:

create table if not exists public.scores (
  id bigint generated by default as identity primary key,
  player_name text not null check (char_length(player_name) between 1 and 18),
  score integer not null check (score between 1 and 10000000),
  created_at timestamptz not null default now()
);

alter table public.scores enable row level security;

create policy "Anyone can read leaderboard scores"
on public.scores for select to anon using (true);

create policy "Anyone can submit a score"
on public.scores for insert to anon
with check (char_length(player_name) between 1 and 18 and score between 1 and 10000000);

4. If Supabase requires it, expose the public.scores table through the Data API / API settings.
5. Save the HTML and reopen it in Chrome while online. Enter a name, play a run, then tap SUBMIT BEST. Tap REFRESH to load the top scores.

IMPORTANT
- The anon/publishable key is intended for client-side use only when Row Level Security is enabled. Never use the service_role or secret key in a browser file.
- This basic public leaderboard is suitable for casual play, not cheat-resistant competition: a browser client can fake scores or spam submissions. For a trusted competitive leaderboard, add server-side score validation/rate limiting using a Supabase Edge Function and avoid accepting arbitrary scores directly.
- Scores are shared publicly with anyone who can access this leaderboard. Choose a nickname; do not enter private personal information.
- Coin wallet and unlocked skin remain local to each browser/device; this version only syncs leaderboard scores online.
